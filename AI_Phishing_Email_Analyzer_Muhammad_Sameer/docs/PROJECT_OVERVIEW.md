# Project Overview

## Project Title
AI-Powered Phishing Email Analyzer with Automated Incident Reporting

## Simple Explanation
This project helps users check whether an email looks safe or suspicious. The user submits email details, and the system analyzes the sender, subject, body, links, and attachment name. After analysis, it gives a phishing score, risk level, detected indicators, explanation, and recommended actions.

## Why It Matters
Phishing is a common cybersecurity threat. Many phishing emails look professional and convincing. This tool helps reduce manual checking time by quickly highlighting suspicious signs.

## Main Workflow

Suspicious Email -> Analyzer -> Risk Score -> Report -> Dashboard

## Technologies Used

- Python backend
- HTML, CSS, JavaScript frontend
- SQLite database
- Local phishing analysis engine
- HTML incident reports
