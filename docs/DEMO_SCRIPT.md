# Demo Script

1. Open the project in VS Code.
2. Run `py app.py`.
3. Open `http://127.0.0.1:8000`.
4. Paste a phishing sample email.
5. Click Analyze Email.
6. Explain the risk level and phishing score.
7. Show detected indicators.
8. Open the incident report.
9. Open Dashboard and show saved reports.
10. Export CSV if needed.

Short explanation:

My project is an AI-powered phishing email analyzer. It checks suspicious email content, detects phishing indicators like urgency, suspicious links, impersonation, login requests, and risky attachments, then classifies the risk level and generates an incident report for faster security response.
